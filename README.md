# NatroMacroAndroid

Experimental Android macro engine for Bee Swarm Simulator inspired by Natro Macro's open-source movement/pattern concepts.

This project does not inject into Roblox, modify the Roblox client, read Roblox memory, use executors, or attempt to bypass anti-cheat. It drives ordinary on-screen touch gestures through Android accessibility APIs. This does not guarantee that automated gameplay is risk-free under Roblox or game rules.
